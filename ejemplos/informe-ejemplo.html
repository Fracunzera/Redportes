IP WAN del router: 192.168.1.33 doble NAT (informada por el router vía UPnP)

El router recibe una IP privada (192.168.1.33): delante hay otro router o el módem del operador haciendo NAT (doble NAT).

IP pública vista desde afuera: 200.51.100.77

  • Doble NAT: el router (192.168.50.1) sale por otro equipo que también traduce (192.168.1.1). Puede ser un segundo router del cliente o el módem del operador. Complica abrir puertos, VPNs y algunas llamadas de VoIP. Si el segundo equipo es el módem del operador, conviene ponerlo en modo bridge.
  • CGNAT: aparece una dirección del rango 100.64.0.0/10 (100.72.0.1). El operador comparte la IP pública entre varios clientes: no se pueden abrir puertos desde afuera. Para acceso remoto hay que pedir IP pública al operador o usar una VPN saliente (WireGuard contra un servidor con IP pública).

Qué se ve desde Internet: Tu salida es por CGNAT: la IP 200.51.100.77 la comparten muchos clientes del operador, así que lo que Shodan vea en ella no es de esta red. Alto Acepta SMBv1
  • 192.168.50.20 CAJA-PC — puerto 445

SMBv1 es la versión vieja de carpetas compartidas de Windows. Es la que usaron WannaCry y otros ransomware para propagarse solos por la red.

Qué hacer: Desactivar SMBv1 (en Windows: 'Activar o desactivar características' → quitar 'Compatibilidad con SMB 1.0'). Si es un NAS o impresora vieja, actualizar firmware o configurar SMB2/3 como mínimo.

Cómo:
# PowerShell como administrador:
Set-SmbServerConfiguration -EnableSMB1Protocol $false -Force
Disable-WindowsOptionalFeature -Online -FeatureName SMB1Protocol -NoRestart
Alto Telnet abierto
  • 192.168.50.40 MikroTik — puerto 23

Telnet manda usuario, contraseña y todo lo que se escribe sin cifrar. Cualquiera en la red puede leerlo.

Qué hacer: Desactivar Telnet y administrar el equipo por SSH o por la web con HTTPS.

Cómo:
/ip service disable telnet
Medio API de MikroTik sin cifrar
  • 192.168.50.40 MikroTik — puerto 8728

El puerto 8728 es la API de RouterOS sin cifrado.

Qué hacer: Si no se usa: /ip service disable api. Si se usa, pasar a api-ssl (8729) y restringir 'address' a las IP de administración.

Cómo:
/ip service disable api
Medio Escritorio remoto (RDP) abierto
  • 192.168.50.20 CAJA-PC — puerto 3389

Normal en una red interna, pero es la puerta de entrada más común de ransomware si llega a quedar publicado a Internet.

Qué hacer: Confirmar que no esté redirigido en el router, exigir NLA y contraseñas fuertes. Para acceso desde afuera, usar VPN.

Cómo:
# PowerShell como administrador (exige NLA):
Set-ItemProperty -Path 'HKLM:\SYSTEM\CurrentControlSet\Control\Terminal Server\WinStations\RDP-Tcp' -Name UserAuthentication -Value 1
